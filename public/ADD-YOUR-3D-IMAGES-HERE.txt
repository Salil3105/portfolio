3D ILLUSTRATIONS — how to make them appear
==========================================

The hero's workspace illustration is now a themed SVG component
(src/components/HeroArt.tsx) instead of a dropped-in image — that's what
lets it render correctly in both light and dark mode. To change it, edit
that file directly rather than swapping in a hero.png.

The About section's portrait is still a real photo. Drop a file into THIS
folder (public/) with this EXACT name:

  avatar.png   → the photo / avatar (About section)

- PNG (transparent background looks best) or JPG — if JPG, rename the
  file to avatar.png anyway, OR change the src in the code:
    Avatar: src/components/Avatar.tsx -> "/avatar.png"
- If it's missing, the site falls back to the built-in CSS scene —
  nothing breaks.
- Whatever backdrop it's cut out against, it'll only look right in light
  mode if that backdrop is flat and matches the tone used in
  globals.css's `:root[data-theme="light"] .avatar-photo` (see the
  comment there) — a gradient or a different flat color will show through
  any semi-transparent edges as a mismatched band.
